# ⏱️ TimeGuessr

A fun web app where you test your sense of time!  
Enter your name, start the timer, and try to stop it right before it runs out.  
How close can you get?

---

## 🚀 Features

- Enter your name to start a game session
- A timer starts counting down
- Try to stop the timer as close as possible to zero
- Built with **React + Vite** for a fast and modern dev experience

---

## 🛠️ Tech Stack

- [React](https://react.dev/) – UI library
- [Vite](https://vitejs.dev/) – build tool
